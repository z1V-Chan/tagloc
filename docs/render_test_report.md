# Render Test Report

This report explains the synthetic test result in `outputs/render_test` and
records the exact commands needed to reproduce it.

## Test Goal

The render test validates the AprilTag localization pipeline under harder
synthetic camera conditions:

- A4 board PDF and layout JSON generation.
- AprilTag detection on rendered images.
- Farther views where the paper occupies about `1/9` to `1/11` of the image.
- Oblique camera angles from `45deg` to `80deg`.
- Irregular polygon occlusions.
- Printed-size correction through measured tag size.
- Known-intrinsics localization.
- No-intrinsics localization after estimating camera intrinsics from the first
  `n` images.

In this report, tilt angle means the angle between the board normal and the
camera-to-board viewing direction. `0deg` is fronto-parallel; larger values are
more grazing.

## Reproduction Commands

Run all commands from the repository root:

```bash
cd /ssd1/czw_new/tagloc
```

Optional cleanup for a fresh run:

```bash
rm -rf outputs/render_test
```

Generate the synthetic render test:

```bash
conda run -n rec python render_test.py --output-dir outputs/render_test
```

Run the known-intrinsics CLI on all evaluation images:

```bash
conda run -n rec python localize_camera.py \
  --board outputs/render_test/board/board_layout.json \
  --tag-size-m 0.0465 \
  --camera outputs/render_test/synthetic_camera.json \
  --output outputs/render_test/localize_known.json \
  --annotate-dir outputs/render_test/localize_known_annotated \
  'outputs/render_test/images/view_1[0-7].png'
```

Run the no-intrinsics CLI. The first 10 images are used for intrinsic
calibration, then all images are localized:

```bash
conda run -n rec python localize_camera.py \
  --board outputs/render_test/board/board_layout.json \
  --tag-size-m 0.0465 \
  --calibration-count 10 \
  --min-calibration-views 5 \
  --output outputs/render_test/localize_selfcalib.json \
  --save-estimated-camera outputs/render_test/localize_estimated_camera.json \
  outputs/render_test/images
```

Run the smoke test used during implementation:

```bash
conda run -n rec python test.py
```

The expected smoke-test summary for this version is:

```text

self-calibration: calibrated

```

The generated PDF/PNG do not include center crosshair lines by default. The
world origin is still the paper center; the reference axes are omitted so the
printed sheet stays clean for detection.

## Scale-Correction Setup

The board layout was generated with:

```text
nominal_tag_size_m = 0.045
```

The rendered board intentionally used:

```text
actual_measured_tag_size_m = 0.0465
```

This simulates a printed board whose physical tag size differs from the nominal
PDF design. During localization, the measured tag size is passed as
`--tag-size-m 0.0465`. The implementation scales every board coordinate by:

```text
scale = 0.0465 / 0.045 = 1.0333333333
```

This validates the intended real-world workflow: print the PDF, measure one tag
edge, and use that measured edge length for pose estimation.

## Conclusion

The updated synthetic test passed. It confirms that:

- The generated board layout can be rendered and detected.
- Farther views with paper area near `1/9` to `1/11` are handled.
- Oblique camera angles from `45deg` to `80deg` are handled in the synthetic
  setup.
- Irregular occlusions are tolerated when enough complete tags remain.
- Measured printed tag size can correct uniform print scaling.
- Known-intrinsics localization remains accurate under the harder render set.
- No-intrinsics mode can estimate camera intrinsics from the first 10 far,
  oblique views and then recover valid poses for subsequent frames.
